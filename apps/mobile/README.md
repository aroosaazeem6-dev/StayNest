# Mobile Application (Phase 11)

This directory will contain the StayNest Flutter mobile application.

## Status

**Not yet initialized.**

The Flutter and Dart SDK are not currently installed in this environment. The mobile application will be properly scaffolded using `flutter create` once Flutter is available.

## Planned When Initialized

- Flutter + Dart project
- Standard Flutter project structure (`lib/`, `android/`, `ios/`, etc.)
- Will consume the NestJS REST API via HTTP client (`dio` or `http`)
- Supports Guest, Host, and Admin roles

## Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- Dart SDK (included with Flutter)

## Initialization

When Flutter is installed, run:

```bash
cd apps/mobile
flutter create .
# or: flutter create -t app . 
flutter pub get
flutter run
```

See the main [README](../../README.md) for the full development roadmap.
